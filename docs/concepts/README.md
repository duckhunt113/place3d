# Model concepts

One concept image per pre-made model, named by its catalog ID: `<catalog ID>.png`
(for example `tree.pine.m.png`, `prop.bench.png`, `sign.shop.blank.png`).

- Used only when making that model: open the one matching the model, nothing else.
- Shows shape and proportions. If it disagrees with the rules (palette colours by name,
  real-world size, triangle budget, faceted foliage vs smooth props), the rules win.
- Must match the scene references in `.claude/skills/art-style/reference/`. Regenerate any
  concept that drifts from that style.
- No real brand logos.
